# Перемещения

Приложение для управляющих сети «Яблонька»: заявки на перемещение товара между точками одного города.
Заявка: **Новая → Принята → Получена** (или Отклонена / Отменена). Всё пишется в Google-таблицу, о каждом шаге приходит пуш.

| Часть | Где |
| --- | --- |
| Приложение | `index.html`, `config.js`, `sw.js`, `manifest.json` → GitHub Pages |
| Сервер и учёт | `apps-script/Code.gs` → Google Apps Script в таблице |
| Доставка пушей | Firebase Cloud Messaging (только доставка, кода там нет) |

## 1. Таблица и сервер
1. Создайте Google-таблицу «Yablonka Перемещения» → Расширения → Apps Script → вставьте `apps-script/Code.gs`.
2. Запустите `setup` → разрешите доступ. Появятся листы **Точки**, **Товары**, **Перемещения**, **Подписки**.
3. Заполните **Точки** (Город | Точка) и **Товары** (Товар | Ед.).
4. Развернуть → Новое развёртывание → Веб-приложение; выполнять от моего имени; доступ — все. URL (…/exec) → `API_URL` в `config.js`.

## 2. Пуши (Firebase, бесплатно)
1. console.firebase.google.com → создать проект (Analytics не нужен).
2. Project settings → General → «Add app» → Web (`</>`) → скопировать `firebaseConfig` в `FIREBASE` в `config.js`.
3. Project settings → Cloud Messaging → Web Push certificates → Generate key pair → ключ в `VAPID_KEY`.
4. Project settings → Service accounts → Generate new private key → скачается JSON.
   Apps Script → Настройки проекта → Свойства скрипта → `FCM_SERVICE_ACCOUNT` = всё содержимое этого JSON.
   **Этот файл секретный — не кладите его в репозиторий.**
5. В Apps Script: Развернуть → Управление развёртываниями → Изменить → Новая версия.
6. В приложении нажмите «Включить» в синей плашке. Проверка: впишите свою точку в `testPush` и запустите.

Android — пуши в установленном приложении. iPhone — только iOS 16.4+ и только если приложение добавлено на экран «Домой».

## 3. GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root. Ссылка: `https://epst812.github.io/peremeshcheniya/`.

## Связь со stock control
Лист **Перемещения**: одна строка = один товар. Считать строки со статусом «Получена», колонку «Получено (факт)».

Пришло на точку за день (A2 — товар, B1 — дата):
```
=СУММЕСЛИМН(Перемещения!L:L; Перемещения!E:E; "Точка 2"; Перемещения!F:F; A2; Перемещения!I:I; "Получена"; Перемещения!K:K; ">="&B1; Перемещения!K:K; "<"&B1+1)
```
Ушло с точки — то же, но `Перемещения!D:D` вместо `E:E`. Из другой таблицы — через `IMPORTRANGE`.
